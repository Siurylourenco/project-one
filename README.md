# 🚀 API Product Dashboard

![Preview do Projeto](./assets/projeto.png)

Um dashboard de produtos moderno e responsivo desenvolvido para praticar consumo de APIs, gerenciamento de estado e estilização avançada com Tailwind CSS.

## 🎯 Objetivo do Projeto
Este projeto foi criado com foco em performance e interface do usuário (UI/UX), simulando um catálogo de e-commerce de alta conversão. O objetivo principal foi dominar o fluxo de dados entre componentes React utilizando TypeScript para garantir a segurança do código.

## 🛠️ Tecnologias Utilizadas
* **React** (v18+)
* **TypeScript** (Tipagem forte para escalabilidade)
* **Tailwind CSS** (Estilização moderna e utilitária)
* **Lucide React** (Ícones limpos)
* **Fetch API** (Consumo de dados externos)

## ⚡ Funcionalidades
- [x] Consumo de API REST em tempo real.
- [x] Grid de produtos responsivo (Mobile, Tablet e Desktop).
- [x] Cards com efeitos de hover e otimização visual.
- [x] Tratamento de estados (Loading e Error).
- [x] Interface limpa (Modern & Clean Design).
